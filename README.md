# Discord Chat App

Ein inoffizieller Desktop-Client für [Discord](https://discord.com), gebaut mit Electron.

> ⚠️ Inoffizielles, privates Projekt – keine Verbindung zu Discord Inc.

## Download

Die fertige `.exe` findest du unter [Releases](../../releases). Einfach herunterladen und installieren.

## Features

- Eigenes, schlankes Fenster (keine Standard-Windows-Titelleiste)
- Screen-Sharing in Calls funktioniert (mit Auswahl zwischen Bildschirm und Anwendungsfenster)
- Systemton-Freigabe unter Windows
- DevTools sind deaktiviert
